# kadou-report（稼動日報 → 営業部別 印刷実績 .xlsx）

稼動日報の `.xls` から、営業部別の `YYYY年M月_◯◯営業部_印刷実績.xlsx` を作るスキルです。
中身は **Claude のスキル `kadou-report` と同じもの**で、ここには
**「Excelが印刷で落ちる」問題を直した版**を置いています。

> 画面の「Excelで保存」ボタンが作る .xlsx はこれとは別物で、
> `kadou-web/xlsx.py` が組み立てています（そちらも同時に直しました）。

```
kadou-report/
  SKILL.md            ← スキルの説明（注意点に印刷まわりの決まりごとを追記）
  scripts/
    kadou_report.py   ← 集計・xlsx出力の本体
```

## 使い方（単体で動かす場合）

```bat
pip install xlrd openpyxl
python kadou-report\scripts\kadou_report.py --month 2025-09 --out 出力 稼動日報1.xls 稼動日報2.xls
```

## スキル側へ反映するには

Claude の設定でスキル `kadou-report` を開き、`SKILL.md` と `scripts/kadou_report.py` を
このフォルダの中身で置き換えてください。（スキルは各PCではなく Claude 側に保存されているため、
このリポジトリを更新しただけでは反映されません。）

## 2026-09 の修正（印刷でExcelが落ちる件）

出力した .xlsx のパッケージ構造そのものは壊れていませんでした。落ちる原因になりうる
「印刷のときだけ通る処理」を3つ直しています。

| | 直した内容 |
|---|---|
| フォント | `Arial` → **`Meiryo`**。日本語グリフを持たない欧文フォントを日本語セルに指定すると、印刷時のフォント差し替えで Excel が異常終了することがある |
| セルのコメント | **廃止**。コメントは図形レイヤー（印刷時に描画される部分）に置かれ、openpyxl が書く VML には位置情報 `<x:Anchor>` が入らない。枝番の内訳は表の下の「【統合した管理番号の内訳】」に通常のセルとして書き出す |
| 印刷範囲 | 繰り返す見出し行（4行目）が印刷範囲の中にあると1ページ目で二重に印刷されるため、印刷範囲を **5行目から** に変更。1〜3行目にあった表題はページヘッダーへ、集計条件はページフッターへ移動。用紙は **A4横** に固定（プリンタ既定に左右されない） |

これでも落ちる場合は、プリンタドライバ側が原因です。プリンタを
「Microsoft Print to PDF」に変えて印刷できるかで切り分けられます。

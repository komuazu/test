# 稼動日報 → 営業部別 印刷実績

## 何をするスキルか

印刷機ごとの稼動日報 `.xls`（例: `新25・A全UV稼動日報.xls`）を1〜複数受け取り、
指定された月のデータだけを抜き出して、営業部別に1ファイルずつ Excel を作る。

出力: `YYYY年M月_本社営業部_印刷実績.xlsx` / `_東京営業部_` / `_池袋営業部_` の3ファイル。

## 使い方

1. 対象の `.xls` と「何月分か」を確認する。月が指定されていなければユーザーに聞く。
   ファイルが手元にない場合は、添付してもらうか、接続フォルダから取得する。
2. スクリプトを実行する。

```bash
pip install xlrd --break-system-packages -q   # 未インストールのときだけ
python scripts/kadou_report.py --month 2025-09 --out ./出力 稼動日報1.xls 稼動日報2.xls ...
```

`--month` は `2025-09` / `2025/9` / `9`（年省略時は今年）のいずれでもよい。

3. 出力された3ファイルを `SendUserFile` でユーザーに渡す。接続フォルダがあれば
   `device_commit_files` でそこにも書き込む。
4. 標準出力に出る件数・通し数を、返答に表を作って報告する。

## 確定している処理ルール

このルールはユーザーと合意済み。**勝手に変えない。** 変更依頼が来たらこのファイルも直す。

**部門の振り分け**（営業担当ｺｰﾄﾞ基準。これ以外のコードは出力対象外）

| 部門 | コード |
|---|---|
| 本社営業部 | 1110, 1120 |
| 東京営業部 | 2100, 2140 |
| 池袋営業部 | 3810, 3820 |

**抽出対象**
- シート名が「25年9月」形式のものだけ。「25年9月30」のような日付付き補助シートは対象外。
- 日付セルにシリアル値が入っている明細行のみ。日次集計ブロック（有効時間・準備合計・
  色合わせ・印刷時間・その他・受注件数）は明細ではないので除外。
- **列位置は月によって違う**（例: 2025年8月のシートには「ｸﾗｲｱﾝﾄ名」列が無い）。
  必ず見出し行の文字で列を特定すること。スクリプトはそう実装してある。
- 「通し枚数」「表版数」「裏版数」は本刷ブロックと集計ブロックの2か所に同名で出る。
  **最初に現れた方（本刷ブロック）**を使う。

**管理番号ごとの統合**
- 枝番は同一管理番号として統合する（`8632175-1` と `8632175-1-2` は1件）。
  基番号 = 管理番号を `-` で切った先頭。末尾の `.0` は落とす。
- 通し数 = グループ内の合計（表刷り＋裏刷りを足した値）
- 色数 = `表/裏` 形式。表版数・裏版数それぞれの**最大値**（同じ版で複数回通した分を
  重複させないため）。片面のみなら `4/0`。
- 印刷日 = グループ内の**初日**。複数日にまたがる行は日付セルを薄い黄色にする。
- 品名 = 初日・管理番号・品名の順で最小の行のもの（枝番ごとに品名が違うケースがあるため）
- ｸﾗｲｱﾝﾄ名 = グループ内の非空値の最頻値 → 同数なら最も長いもの

**並び順**
1. 営業担当ｺｰﾄﾞ 降順
2. ｸﾗｲｱﾝﾄ名 降順（NFKC正規化して `㈱` と `（株）`、全角半角スペースの違いを同一視。空欄は各コードの末尾）
3. 印刷日 降順

**列構成**（10列・この順序）

`管理番号 / ｸﾗｲｱﾝﾄ名 / 品名 / 今年の動向 / 無しの場合の代替対策 / 対策通し数 / 営業担当ｺｰﾄﾞ / 印刷日 / 色数 / 通し数`

- 「今年の動向」「無しの場合の代替対策」「対策通し数」は**空欄の手入力欄**（黄色セル・青文字）。
  データを埋めてはいけない。
- 合計行と「差引（通し数 − 対策通し数）」行、充足率（%）を数式で入れる。
- 表全体に罫線（外周は濃紺の太罫、内側は細罫）。印刷設定は A4 横・横1ページ・見出し行(4行目)の繰り返し。
- 枝番を統合した行は管理番号を太字にし、その内訳は表の下に「【統合した管理番号の内訳】」として書き出す。

## 注意点

- `.xls`（旧形式）を読むので `xlrd` が要る。`openpyxl` では読めない。
- **Excel が印刷で落ちないための決まりごと**（2026-09 に対処済み。元に戻さない）
  - フォントは日本語グリフを持つもの（`Meiryo`）。`Arial` など欧文専用フォントを日本語セルに
    指定すると、印刷時のフォント差し替えで Excel が異常終了することがある。
  - **セルのコメントは使わない**。コメントは図形レイヤー（印刷時に描画される部分）に置かれ、
    openpyxl が書く VML には位置情報 `<x:Anchor>` が入らないため、印刷・印刷プレビューで
    不具合の原因になる。内訳は通常のセルに表として書く。
  - 繰り返す見出し行は印刷範囲の外に置く（印刷範囲は5行目から）。範囲の中にあると
    1ページ目で見出しが二重に印刷される。表題はページヘッダーに出す。
- 出力ファイルは openpyxl が書くため数式のキャッシュ値が無い。Excelで開けば自動計算されるので
  そのまま渡してよい。**LibreOffice での再計算はかけない**（列幅の小数点以下が丸められる）。
- ユーザーが調整した既存ファイルを加工する場合は、コピーしてシートを消す方式にする。
  作り直すと列幅が失われる。
- 対象月のシートが無いファイルがあれば、その旨を警告として報告する（処理は続行する）。

## 検証

出力したら必ず次を確認して報告する。

- 部門ごとの「明細行数 → 統合件数 → 通し数」
- 統合前後で通し数の合計が変わっていないこと
- 対象月のシートが見つからなかったファイルの有無

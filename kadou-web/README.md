# 稼動日報 印刷実績ビューア（26年）

`★新・26年稼動` フォルダの稼動日報 `.xls` を読み込み、
**26年すべての月 × 営業部別（本社・東京・池袋）** をブラウザで見られるようにするアプリです。

抽出・統合のルールは、これまでの「月次の営業部別 印刷実績集計」と**まったく同じ**です。

> **元のExcelファイルは絶対に変更しません。**
> 読み込みは必ず一時フォルダへコピーしてから行い、稼動日報フォルダには何も書き込みません。
> 画面で入力した内容は、このアプリのフォルダ内の `memo.json` に保存されます。

---

## 使い方

### 1. 起動する

このフォルダごと社内PCにコピーして、**`起動.bat` をダブルクリック**するだけです。

* 黒い画面が開いて稼動日報を読み込み、ブラウザが自動で立ち上がります
* 閉じるときは、黒い画面で **Ctrl + C** を押してください
* 初回だけ、必要なライブラリ（xlrd）の導入に少し時間がかかります

Python が入っていない場合は
[python.org](https://www.python.org/downloads/windows/) からインストールし、
インストール時に **「Add python.exe to PATH」にチェック**を入れてください。

### 外出先から見る（iPad・スマホ）

社内のPCを1台サーバーにして、外の端末から見られます。

**1. サーバーにするPCで用意する**（稼動日報フォルダが見えるPCを選びます）

1. `password.txt` を作り、1行めに**合い言葉**を書く（このファイルは共有されません）
2. **`サーバー起動.bat`** をダブルクリック
3. 黒い画面に出る `http://192.168.〇.〇:8765/` が、ほかの端末から開くアドレスです

この画面を閉じるとサーバーは止まります。PCは電源とネットワークを入れたままに
してください。同じ社内ネットワークの端末なら、これだけで見られます。

> **サーバーにするPCで最初に用意するもの**
>
> 1. **アプリを置く**… 好きなフォルダに `セットアップ.bat` を置いてダブルクリック
>    （`arunasiweb` フォルダに取ってきます）。git が入っていれば、次からは
>    同じファイルで最新に更新できます。フォルダごとコピーしても構いません
> 2. **稼動日報フォルダを教える**… 共有中は画面から変えられないので、先に決めます。
>    `サーバー起動.bat --src "D:\稼動日報"` のように1回だけ渡すと `config.json` に
>    残り、次からは付けなくて構いません。ネットワーク上のフォルダは、`U:` のような
>    ドライブ文字ではなく `\\サーバー名\共有名\…` の形で書いてください
>    （別のアカウントで動かすとドライブ文字が無いことがあるためです）
> 3. **合い言葉**… `password.txt` を作って1行めに書く
> 4. **記入欄を引き継ぐ**… これまで使っていたPCの `memo.json` を、
>    サーバーの `kadou-web` フォルダにコピーします（今年の動向などが残ります）
> 5. **ファイアウォール**… 初回に「アクセスを許可しますか」と聞かれたら許可します
>    （プライベートネットワークだけで構いません）
> 6. **開いたままにする**… 黒い画面を閉じると止まります。PCの電源と
>    ネットワークは入れたままにしてください
>
> Python と xlrd は `サーバー起動.bat` が確かめます。共有では「フォルダを選ぶ」を
> 使わないので、tkinter は無くても動きます。

**2. 外から入る方法**（上ほど安全です）

| 方法 | 中身 |
|---|---|
| **会社のVPN** | 社内にいるのと同じ状態になります。追加の設定は要りません。IT担当にご確認ください |
| **端末どうしをつなぐVPN**（Tailscale など） | サーバーPCとiPadに同じアプリを入れるだけ。ルーターの設定は不要で、通信は暗号化されます |
| ルーターのポート開放 | **おすすめしません。**合い言葉がそのまま流れ、世界中から接続を試されます |

**3. 共有で使うときの決まり**

* 開くときに合い言葉を聞かれます。合い言葉は全員で共通で、誰が見たかは記録しません
* **稼動日報フォルダの変更と「フォルダを選ぶ」は使えません。**読むフォルダは
  サーバー側（`config.json`）で決めます。画面から変えられると、サーバーの中の
  どのフォルダでも読めてしまうためです
* 「データ更新」は誰でも押せます（1〜2分かかります）。同時に1つだけ動きます
* 記入欄（今年の動向など）は全員で共通です。同じ欄を同時に直すと後の人が勝ちます

自分のPCだけで使うときは、これまでどおり **`起動.bat`** です（合い言葉なし・
自分のPCからだけ開けます）。

### 2. フォルダの場所

**複数のフォルダをまとめて読みます。** 実在するフォルダだけを読み、無いものは黙って飛ばします。
初期設定は次の3つです。

```
（デスクトップ）\☆平版印刷課稼働日報                  … 今年ぶん＋過去分
（デスクトップ）\13年稼動～25年稼動                   … 前の置き場所（あれば）
U:\製造本部\…\☆第二工場日報・稼動報告               … 同じものの元
\\ntfham001\Users\製造本部\…\☆第二工場日報・稼動報告  … U: が無いPC用（上と同じ場所）
```

`U:` の実体は `\\ntfham001\Users` なので、上2つは同じ場所への別の行き方です。
**同じファイル（名前・サイズ・更新日時が同じ）は1つだけ数える**ので、両方通るPCでも二重になりません。

変えたいときは画面右上の **「設定」** で変更できます。
**「フォルダを選ぶ…」** を押すと、いつものフォルダ選択画面が開くので、
パスを書き写さずにその場で選べます（選んだフォルダは欄に追記されます）。
手で書く場合は **1行に1フォルダ**ずつ、要らない行は消してください。
エクスプローラーの「パスのコピー」で付いてくる前後の `"` は、そのままでも構いません。
「保存して読み直す」を押すと、その場で読み直します。設定は `config.json` に残ります。
フォルダが見つからないときは、どこまでが実在するか＋その中のフォルダ名を一覧で出します。

フォルダ名の **`～`（全角チルダ）と `〜`（波ダッシュ）** は見た目が同じで取り違えやすいため、
どちらで書いても同じフォルダとして探します（全角半角・空白の違いも同様）。
別名で見つかったときは、起動時の黒い画面に実際に読んだフォルダ名が出ます。

### どのファイルを読むか

指定したフォルダの**下をたどって年フォルダを探し**、その年フォルダごとに
稼動日報を1セットだけ読みます。

| 年フォルダ | 読むファイル |
|---|---|
| `★新・NN年稼動` | 直下の `新…稼動日報.xls`（`新26・三菱稼動日報.xls` など） |
| `NN年稼働` | 直下の `…稼動日報.xls`（`★新` がまだ無い年・月を補う） |

`稼動` と `稼働`、全角半角、`～` と `〜` の違いは同じものとして扱います。

**入れ物のフォルダの名前は見ません。**そのため、年度が変わって

```
☆平版印刷課稼働日報\
├ ★新・26年稼動\            →  27年になると 13年～26年稼働\ の中へ移り
└ 13年稼動～25年稼動\        →  名前が 13年～26年稼働\ に変わり
                              新しく ★新・27年稼動\ ができる
```

のように**フォルダ名が変わっても、設定を直さずに最新のデータが読めます**。
指定するのはいちばん外側のフォルダ1つで構いません。

同じ年・月が `★新` と古いフォルダの両方にあるときは **`★新` を正**とし、古い
ほうの同じ月は数えません。2015年のように `★新` が8月から始まっている年は、
**1〜7月だけ**古いフォルダから採ります。入れ替えた月は起動時の画面と「注意」に
出ます。

同じ年のフォルダが何か所にもあるときは、**いちばん浅いところにあるものだけ**を
読みます。深さが同じときは、設定で先に書いたフォルダを使います。控えのフォルダ
（`☆平版印刷課印刷稼働日報` の下など）に置かれた写しは階層が深いので、これで
自然に外れます。同じ日報を何度も数えないためです（実際に2016年は4回数えて
いました）。

次のものは**読みません**。

* 年フォルダの中の `日報取込用` などのサブフォルダ（同じ日報の写しです）
* 集約表・稼働率表・稼働実績表・断裁機・軽ｵﾌ印刷機（名前で対象外になります）
* **2013年より前**のデータ（古い試験用の日報が混ざっているため）

年フォルダが1つも無いフォルダを指定したときは、これまでどおり配下の `.xls` を
全部読みます。

### 3. 年の切り替え

読み込んだフォルダに複数の年が入っていれば、**画面左上のプルダウンで年を切り替え**られます
（13年〜25年のフォルダなら 2013〜2025 が並びます）。年が1つだけのときは出ません。

シート名（例「25年9月」）から年を判別するので、フォルダ名や置き場所は問いません。

### 4. 日報が更新されたら

画面右上の **「データ更新」** を押すと、フォルダを読み直して最新の内容になります。
（入力済みの記入欄はそのまま残ります）

## 画面

| タブ | 内容 |
|---|---|
| **年間サマリー** | 年間の通し数・件数と部署別の構成比、**前年との比較**、月別の積み上げ棒グラフ、月×部署のマトリクス表 |
| **月別明細** | 月と営業部を選んで明細を表示。集計Excelと同じ10列・同じ並び順 |
| **得意先別** | 得意先ごとのランキング。**年間**と**月ごと**を切り替えられます |
| **日報明細** | 稼動日報の内容を、統合前の1行1行・**日報の列そのまま**で表示 |
| **元ファイル** | 読み込んだ稼動日報の一覧と、統合前後で通し数が変わっていないことの検証結果 |

* マトリクス表の数字をクリックすると、その月・その営業部の明細に飛びます
* 各画面から **Excelで保存**ができます。書き出したファイルは見出しに色と罫線が
  付き、見出し行を固定してオートフィルタが付いた表になります。数値は数値のまま
  （3桁区切り）入るので、そのまま並べ替えや集計ができます
* 画面右上の **「印刷」** で、いま開いているタブをそのまま紙に出せます。
  上部のメニューやボタンは印刷されず、代わりに「2026年 稼動日報 印刷実績
  年間サマリー」のような見出しが付きます。用紙はA4横、表が複数ページに
  またがるときは見出し行を各ページに繰り返します
* **「PDFで保存」** を押すと同じ印刷画面が開きます。**「送信先（プリンター）」で
  「PDFとして保存」**（または「Microsoft Print to PDF」）を選ぶとPDFになります

### 前年と比べる

「年間サマリー」に**前年との比較**が2つ出ます。

* **前年との比較** … 部署ごとの通し数・件数を前年と並べ、増減と前年比を出します
* **月別 前年比** … 月ごと・部署ごとの前年比と増減。マスにマウスを乗せると
  今年と前年の実数が出ます
* **月別 通し数のグラフ** … Excel の積み上げ棒グラフと同じ形です。左が通し数の
  目盛り、下が月、凡例は下。段と段は**区分線**でつないでいるので、部署ごとの
  増減の流れが追えます
* **前年と比較** … 同じ積み上げの形のまま、月ごとに**今年と前年の2本**が並びます。
  **塗り＝今年／斜線＝前年**で、2本の段どうしも区分線でつなぐので、部署ごとの
  増減がその場で分かります。プルダウンで「全社」や1つの部署だけにすると、
  その範囲の2本だけになります
* 棒にマウスを乗せると、その月・その部署の数字が出ます。月ごとの前年比は
  「前年との比較」と「月別 前年比」の表で見られます

前年より**減った数字は赤**、**増えた数字は太字**にしています（表・グラフとも）。

**前年は「同じ月まで」で比べます。**たとえば今年が8月までしか入っていなければ、
前年も1〜8月だけを足して比べるので、期の途中でも見比べられます。
前年のデータが無い年（いちばん古い年）では、この2つは出ません。

どちらも CSV で保存できます。前年の集計は `years.json` に小さくまとめてあるので、
前年の `data_<年>.json`（10MB前後）を読み込まずに表示しています。

### 月ごとのクライアント別を見る

「得意先別」タブの左上のプルダウンで **年間（全月）／各月** を切り替えます。

* **年間** … 得意先ごとの年間合計と、1月〜12月の内訳
* **月を選ぶ** … その月の得意先ランキングと、**品名・管理番号・通し数の内訳**

営業部（全社／本社／東京／池袋）でも同時に絞り込めます。
同じ得意先が違う書き方で入っていても、まとめて数えます。

* `㈱` `（株）` `(株)` `株式会社` の**有無と書き方の違い**（有限会社・合同会社なども同じ）
* 半角カナと全角カナ、全角英数と半角英数、全角半角スペースの違い

たとえば「武陽ｶﾞｽ（株）」「武陽ガス」「武陽ガス株式会社」は1社として合算します。
表の名前は、その中でいちばん多く使われている書き方を出し、
まとめた書き方は「表記3」バッジにマウスを乗せると確認できます。

> 稼動日報の**ｸﾗｲｱﾝﾄ名の欄は 2025年9月から記入**されています。
> それ以前の日報は空欄のため、この画面では「（得意先名なし）」にまとまります。

### 日報作成に使った内容を見る

集計後の10列だけでなく、**稼動日報の元の内容**もそのまま確認できます。

* **「日報明細」タブ** … 月・機械を選ぶと、統合前の明細行を日報の見出し列そのままで表示します。
  下段には日次集計ブロック（有効時間・準備合計・色合わせ・印刷時間・その他・受注件数）も出ます。
* **「月別明細」の管理番号の左にある ▶** … その管理番号の内訳（枝番を含む日報の元の行）が開きます。

列は日報の見出しから自動で拾うため、月によって列構成が違っても、そのまま表示されます。
同じ見出しが2か所にある列（通し枚数・表版数・裏版数）は、2つめに「（集計）」を付けて区別しています。
**集計に使うのは「（集計）」が付かない本刷ブロック**の方です。

## 集計ルール（従来の集計と同じ）

**部署の振り分け**（営業担当ｺｰﾄﾞ基準）

| 部署 | コード |
|---|---|
| 本社営業部 | 1110, 1120 |
| 東京営業部 | 2100, 2140 |
| 池袋営業部 | 3810, 3820 |
| 生産管理部（工務） | 6930 |
| その他 | 上のどれでもないコード（1150・3110・3150 など） |

**「その他」も集計に入ります。**以前は3営業部のコード以外を落としていましたが、
落とすと通し数が実際より少なくなるため、まとめて「その他」として数えます。
どのコードが入ったかは、年間集計の「その他」の行に出ます（多いときは4つまで）。
営業担当ｺｰﾄﾞが空欄の行や、数字でない行は明細ではないので、これまでどおり読みません。

**抽出対象**

* シート名が `26年1月` 形式のものだけ（`26年1月30` のような日付付き補助シートは対象外）
* 日付セルにシリアル値が入っている明細行のみ
  （有効時間・準備合計・色合わせ・印刷時間・その他・受注件数 の日次集計ブロックは除外）
* 列の位置は月によって違うため、見出しの文字で列を特定します
* 「通し枚数」「表版数」「裏版数」は本刷ブロック（最初に現れた方）を採用します

**管理番号ごとの統合**

* 枝番は同一管理番号として統合（`8632175-1` と `8632175-1-2` は1件）
* 通し数 = グループ内の合計（表刷り＋裏刷り）
* 色数 = `表/裏`。表版数・裏版数それぞれの**最大値**（同じ版で複数回通した分を重複させない）
* 印刷日 = グループ内の**初日**。複数日にまたがる行は日付セルが黄色
* 品名 = 初日・管理番号・品名の順で最小の行のもの
* ｸﾗｲｱﾝﾄ名 = グループ内の非空値の最頻値 → 同数なら最も長いもの

**並び順**

1. 営業担当ｺｰﾄﾞ 降順
2. ｸﾗｲｱﾝﾄ名 降順（`㈱` と `（株）`、全角半角スペースの違いは同一視。空欄は各コードの末尾）
3. 印刷日 降順

**記入欄（山吹色の3列）**

`今年の動向` / `無しの場合の代替対策` / `対策通し数` は手入力欄です。
入力した内容は**消えないように3か所に保存**します。

| 場所 | 中身 |
|---|---|
| `kadou-web/memo.json` | 本体 |
| `kadou-web/memo_前回.json` | 1つ前の内容（打ち間違いを戻すため） |
| `%APPDATA%\kadou-web\memo.json` | 控え。アプリのフォルダを入れ替えても残る |

アプリを取り直して `memo.json` が無くなっても、起動時に控えから自動で戻します。

入力すると合計・差引（通し数 − 対策通し数）・充足率が自動で計算されます。
内容は `memo.json` に保存され、**元のExcelには書き戻されません**。

## ファイル構成

```
kadou-web/
├── 起動.bat            ← これをダブルクリック（自分のPCで見る）
├── サーバー起動.bat     ← 社内サーバーにして、ほかの端末からも見る
├── password.txt         合い言葉（共有するときだけ作る。共有されません）
├── server.py            ローカルサーバー（記入欄の保存・データ更新）
├── build.py             稼動日報フォルダ → web/data.json
├── kadou_core.py        抽出・統合ルール＋日報の全列の取り込み（元ファイルは読み取りのみ）
├── make_zip.py          配布用ZIPを作る
├── web/
│   ├── index.html       画面
│   ├── app.js           表示・集計・CSV出力
│   ├── style.css        見た目
│   ├── years.json       年の一覧（起動のたびに作り直し）
│   └── data_<年>.json   年ごとのデータ（起動のたびに作り直し）
├── config.json          フォルダの場所・対象年（初回起動時に作成）
├── memo.json            記入欄の内容（入力すると作成）
└── tests/
    ├── make_fixture.py  検証用のダミー稼動日報を作る
    └── ui_test.py       画面の自動テスト
```

## コマンドで使う場合

```bash
# データだけ作る（--src は複数指定できる。--year を省くと入っている年を全部）
python build.py --src "C:\Users\...\Desktop\13年稼動～25年稼動" --src "U:\...\★新・26年稼動"
python build.py --src "U:\...\★新・26年稼動" --year 2026    # 年を絞る場合

# サーバーを起動（ポート変更・ブラウザを開かない、なども可）
python server.py --src "C:\Users\...\Desktop\13年稼動～25年稼動" --port 8765
python server.py --no-build      # 読み直さず前回のデータで起動
```

出力は `web/years.json`（年の一覧）と `web/data_<年>.json`（年ごとのデータ）です。

稼動日報 印刷実績ビューア（26年）  使い方
============================================================

1) このフォルダの「起動.bat」をダブルクリックしてください。
   （日本語のファイル名が開けない場合は「start.bat」でも同じです）

2) 黒い画面が開いて稼動日報を読み込み、
   ブラウザが自動で立ち上がります。

3) 終わるときは、黒い画面で Ctrl + C を押してください。

------------------------------------------------------------
■ 初回だけ

Python が入っていないPCでは起動できません。
その場合は下記からインストールしてください。
  https://www.python.org/downloads/windows/
  ※インストール時に「Add python.exe to PATH」に必ずチェック

Python があれば、初回に必要な部品（xlrd）を自動で入れます。

------------------------------------------------------------
■ 読み込むフォルダ

  U:\製造本部\第2工場\【第二工場】\☆第二工場日報・稼動報告
    \☆第二工場日報・稼動報告\★新・26年稼動

U: が割り当てられていないPCでは、下記も自動で試します。

  \\ntfham001\Users\製造本部\第2工場\【第二工場】
    \☆第二工場日報・稼動報告\☆第二工場日報・稼動報告\★新・26年稼動

違っていれば、画面右上の「設定」から直せます。
フォルダが見つからないときは、どこまでのフォルダが実在するかと、
その中にあるフォルダ名の一覧が黒い画面に出ます。

------------------------------------------------------------
■ 画面

  年間サマリー … 年間の通し数、営業部別の構成比、月別グラフ
  月別明細　　 … 月・営業部を選んで明細（集計Excelと同じ10列）
  得意先別　　 … 得意先ランキング（年間／月ごとを切替）
  日報明細　　 … 稼動日報の内容を統合前の1行1行そのまま
  元ファイル　 … 読み込んだ日報の一覧と検証結果

CSV出力・印刷・絞り込みができます。

------------------------------------------------------------
■ 大事なこと

元のExcelファイルは一切変更しません。
読み込みは必ず一時フォルダへコピーしてから行い、
稼動日報フォルダには何も書き込みません。

画面で入力した「今年の動向 / 代替対策 / 対策通し数」は、
このフォルダの memo.json に保存されます。
